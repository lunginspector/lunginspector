## lunginspector
making idevices do things they probably shouldn't be doing. manager and developer at [jailbreak.party](https://github.com/jailbreakdotparty).

## my projects (all of which under jailbreak.party)
- [PartyUI](https://github.com/jailbreakdotparty/PartyUI) - Simple SwiftUI package containing a bunch of random UI components I like to reuse.
- [PancakeStore](https://github.com/jailbreakdotparty/PancakeStore) - A jailed app store app downgrader, based off of MuffinStoreJailed. Supports iOS 16.4+ and does not use any exploits.
- [Lithium](https://github.com/jailbreakdotparty/Lithium) - A very basic and limited customization tool that uses only MDM configuration profiles, for iOS 16.0 and later.
- [Accessible](https://github.com/jailbreakdotparty/Accessible) - A jailed filesystem utility for iOS 16+, utlizing the Shortcuts application.
- [Bridge](https://github.com/jailbreakdotparty/Bridge) - An internal system app opener & extractor for jailed iDevices running iOS 16 and later.
